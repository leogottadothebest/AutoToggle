# Changelog

[English](CHANGELOG.md) · [中文](CHANGELOG.zh-CN.md)

All notable changes to AutoToggle are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-08-16

### Added

- Built-in auto-update via Sparkle 2: checks for updates on launch and via **Settings → About → Check for Updates…**, then downloads and installs new versions automatically

## [1.2.0] - 2026-08-15

### Added

- Complete English interface: switch between Chinese / English / Follow System in **Settings → Language** (a restart applies the change)

### Fixed

- Fixed the interface staying entirely Chinese after switching to English: the language setting wasn't synced to `AppleLanguages`, and many UI strings lacked English translations; language override is now wired up and all English translations are complete
- Fixed the menu bar dropdown panel's top arrow color not matching the body: removed the opaque `windowBackground` overlay so the `NSPopover`'s own material (including the arrow) shows through; also wired the light/dark appearance setting into `NSApp.appearance`
- Fixed duplicate activity-log entries: a single action no longer produces two records ("quit app / launch app" + "idle quit / scheduled launch"); triggered actions now log only semantic entries (idle quit / scheduled launch / scheduled quit / idle hide), and a manual quit is logged separately by the menu bar
- Darkened the menu bar quit button (now uses the primary color, distinct from the gray utility buttons); removed the fixed width from the log-category picker to avoid truncating English labels

## [1.1.0] - 2026-08-14

### Added

- App picker now scans `/Applications/Utilities` (Terminal, Activity Monitor, etc.) and deduplicates by bundle ID
- App list sorted by interface language (ascending): pinyin for the Chinese UI, alphabetical for the English UI (both the managed-apps overview and the app picker)
- Clickable letter index on the right side of the app picker, with the search field auto-focused when opened
- Idle-duration "custom" now accepts a manually typed number of minutes (with a stepper)
- Settings gains an "Accessibility permission" status display with a one-click request
- The menu bar shows "scheduled tasks" (scheduled launch/quit + relative time) alongside managed apps; disabled (off) tasks stay listed and can be toggled via the right-side switch

### Changed

- Menu bar icon now uses `NSStatusItem` + `NSPopover(.transient)`, fixing the issue where opening the menu bar activated the app and stole keyboard focus from other apps (panel buttons are now clickable)
- Opening the main window from the menu bar now dismisses the panel first and brings the window to the front (`.activateIgnoringOtherApps` + `orderFrontRegardless`, re-openable even after closing)
- Accessibility permission state now re-checks periodically (every 3 seconds) so it syncs promptly after granting
- Clicking the red close button hides the app from the Dock (pure menu-bar mode); clicking the menu bar "Main Window" re-shows it and restores the Dock icon
- Release builds are now signed with a stable self-signed certificate (generated by `scripts/bootstrap-signing.sh`, not ad-hoc), so the Accessibility permission no longer expires on every rebuild; Debug stays ad-hoc for debugger attachment

### Fixed

- Fixed a scheduled-launch app being misjudged as "idle" and quit within tens of seconds: the idle baseline is now reset on app launch so a stale active time doesn't trigger the idle rule immediately (e.g. Baidu Netdisk being idle-quit tens of seconds after its scheduled open)
- Fixed "Accessibility already granted in System Settings, but the app always shows unauthenticated": the root cause was the ad-hoc signature's designated requirement being a cdhash that changes on every rebuild, invalidating the TCC grant; the stable self-signed certificate makes the identity depend only on bundle id + certificate, which no longer changes across rebuilds
- Refactored the authorization module: extracted code-signing diagnostics (detects ad-hoc signing) and emits actionable logs when unauthenticated, to help pinpoint the root cause
- Fixed "Accessibility granted at runtime but still shows unauthenticated": macOS caches the grant for a running process, so a restart is required for it to take effect; returning from System Settings now shows a "restart to apply" prompt with a one-click restart

## [1.0.0] - 2026-08-13

First public release.

### Added

- Scheduled rules: automatically launch or quit apps at specific times and weekdays
- Idle detection: auto-quit or hide apps after they have been idle for a set duration
- Fake-idle detection: intelligently recognizes audio playback, meetings, and similar scenarios to avoid false quits
- Menu bar resident: runs quietly in the menu bar without occupying Dock space
- Launch at login: starts automatically on sign-in, no manual steps
- Privacy-first: all data stored locally, with no network requests and no data upload
- Native Chinese interface, optimized for WeChat / DingTalk / Feishu and other domestic apps
- Three-tier graceful app-quit strategy (AppleScript quit → terminate → SIGTERM)

### Security

- Enabled Hardened Runtime and minimized entitlements
- Imported profile files gain size and field-range validation
